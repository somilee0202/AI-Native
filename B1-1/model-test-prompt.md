# 모델 비교용 복붙 프롬프트

아래 프롬프트를 ChatGPT, Claude, Gemini에 각각 동일하게 입력한다.

각 모델에는 `0623 익명 스타트업 회의.txt` 파일을 함께 첨부한다.

응답을 받은 뒤 각 모델의 원문 응답을 보관하고, `model-comparison-report.md`에 모델별 결과 요약과 점수를 기록한다.

```txt
너는 스타트업 회의록 정리 어시스턴트다.
첨부한 `0623 익명 스타트업 회의.txt`는 실제 스타트업 회의 녹취록이다.
첨부 파일 전체를 읽고 회의록을 정리해줘.

출력 형식:
1. 한줄 요약
2. 결정사항
3. Action Items: 할 일 / 담당자 / 마감일 / 근거
4. 리스크
5. 후속 일정
6. 확인 필요 사항

규칙:
- 원문에 없는 담당자, 마감일, 예산, 정책은 만들지 말 것.
- 불명확한 내용은 확인 필요로 표시할 것.
- 실무 공유용으로 간결하게 작성할 것.
- 회의 내용이 길더라도 핵심 의사결정과 실행 항목을 우선 정리할 것.
- 녹취 오류로 보이는 표현은 임의로 확정하지 말고 맥락상 추정 또는 확인 필요로 표시할 것.
- 참석자는 원문의 `참석자 1`, `참석자 2` 같은 표기를 유지할 것.
```

## 응답 수집 양식

아래 형식으로 각 모델의 결과를 붙여넣으면 비교 보고서를 작성하기 쉽다.

```md
## ChatGPT

- 모델명:
- 사용 환경: 웹
- 요금제: 유료
- 사용 날짜: 2026/06/26
- 주요 설정: 기본값

```txt

| TTS/언어 기능 | 7~8월 기능 구현 시 언어·목소리·TTS 설정을 고려해야 함 |
| 지식재산권 | 익명 서비스 이름, 로고 등 지식재산권 관련 정부 지원 프로그램 확인 필요 |
| 앱 전환 | 앱 등록용 사업자 식별번호 이슈 해결 후 앱 계정 생성 및 검수 진행 예정 |

## 4. 리스크

| 리스크 | 내용 |

| 데이터 해석 오염 | 광고 플랫폼 B와 분석 도구 A 데이터 기준이 다르고 중복/퍼스트터치 처리 차이로 수치 해석에 주의 필요 |
| 앱 전환 지연 | 앱 등록용 사업자 식별번호 문제로 앱 계정 생성 및 검수 일정이 지연될 수 있음 |

## 6. 확인 필요 사항

- 공유 URL을 `share`가 아닌 `book` 형태로 접근했을 때 **정확히 어떤 권한까지 노출되는지** 확인 필요
- 비로그인 사용자 / 로그인 사용자 / 책 소유자 / 공유받은 사용자별 접근 정책 확인 필요
- `동화책 완성하기` 버튼을 **고정 버튼으로 둘지**, CTA 위치를 어떻게 바꿀지 결정 필요
- 사진 제한을 **10장 유지할지, 15장 등으로 늘릴지** 결정 필요
- 10장 초과 선택 시 UX를 “초과 선택 불가”로 할지 “선택 후 줄이기”로 할지 결정 필요
- 로딩 화면에서 예상 시간, 진행률, 생성 중 페이지 수 등을 표시할 수 있는지 기술 검토 필요
- 정적 이미지 선노출 방식이 브랜드 경험을 해치는지, 이탈률 감소에 도움이 되는지 판단 필요
- 한영 전환 버튼의 위치/문구/자동 언어 감지 필요성 확인 필요
- 영어 외 베트남어 등 입력 시 결과 언어 정책 확인 필요
- 그림체 옵션을 줄일지, 예시 이미지를 바꿀지 결정 필요
- 외부 이미지 생성 서비스 A/API 동시 요청 제한을 현재 트래픽 기준으로 어느 정도까지 감당 가능한지 산정 필요
- 엔터프라이즈 요금제 또는 계정 확장 시 비용/효과 확인 필요
- 앱 등록용 사업자 식별번호 수정 요청 처리 상태 확인 필요
- TTS/언어 기능을 자체 구현할지 외부 솔루션을 임시 활용할지 확인 필요
```

## 1. 한줄 요약

광고 기간 사용자 리플레이 분석 결과를 공유하고, 제품 UX 개선 이슈(완성하기 버튼 가시성, 사진 장수 제한, 로딩 경험, 동영상 생성 지연)와 기술 인프라 제약(이미지 AI 동시 요청 한계)을 점검하며 우선 대응 방향을 논의함.

---

## 2. 결정사항

- **완성하기 버튼 고정 표시:** 미리 보기 화면에서 완성하기 버튼이 스크롤 아래에 있어 이탈 발생 → 화면 고정(sticky) 처리하기로 함
