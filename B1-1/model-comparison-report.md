# 모델 비교·선정 보고서

## 1. 비교 목적

스타트업 회의록 요약 자동화 과업에 가장 적합한 LLM을 선정하기 위해 3종 이상의 모델에 동일한 입력을 제공하고 결과를 비교한다.

비교의 핵심은 단순히 자연스러운 답변을 만드는 능력이 아니라, 회의 메모에 있는 사실만 사용하면서 결정사항, Action Items, 리스크, 후속 일정을 안정적으로 분리하는 능력이다.

## 2. 비교에 사용한 동일 입력

아래 프롬프트와 `0623 익명 스타트업 회의.txt` 첨부 파일을 모든 모델에 동일하게 제공한다.

```txt
너는 스타트업 회의록 정리 어시스턴트다.
첨부한 `0623 익명 스타트업 회의.txt`는 실제 스타트업 회의 녹취록이다.
첨부 파일 전체를 읽고 회의록을 정리해줘.

출력 형식:
1. 한줄 요약
2. 결정사항
3. Action Items: 할 일 / 담당자 / 마감일 / 근거
4. 리스크
5. 후속 일정
6. 확인 필요 사항

규칙:
- 원문에 없는 담당자, 마감일, 예산, 정책은 만들지 말 것.
- 불명확한 내용은 확인 필요로 표시할 것.
- 실무 공유용으로 간결하게 작성할 것.
- 회의 내용이 길더라도 핵심 의사결정과 실행 항목을 우선 정리할 것.
- 녹취 오류로 보이는 표현은 임의로 확정하지 말고 맥락상 추정 또는 확인 필요로 표시할 것.
- 참석자는 원문의 `참석자 1`, `참석자 2` 같은 표기를 유지할 것.
```

## 5. 모델별 결과 요약

원문 응답은 `model-test-prompt.md`에 보관했다.

### ChatGPT 결과 요약

ChatGPT는 긴 회의 녹취록에서 공유 URL, 미리보기/완성하기 UX, 사진 선택 제한, 로딩/생성 상태, 그림체 옵션, 언어 전환, TTS, 지식재산권, 앱 전환 등 주요 논의 주제를 폭넓게 추출했다. 출력 형식도 요청한 6개 항목을 모두 지켰고, Action Items 표에 근거를 함께 넣어 실무 문서로 활용하기 좋았다.

다만 일부 항목은 실제로 확정된 결정이라기보다 논의 또는 검토에 가까운 내용을 `결정사항`에 포함했다. 담당자와 마감일을 대체로 `확인 필요`로 둔 점은 환각 방지 측면에서 적절했다.

### Claude 결과 요약

Claude는 회의 핵심을 비교적 정확하게 압축했고, 결정사항과 미확정 사항을 구분하려는 태도가 가장 뚜렷했다. 특히 녹취 오류로 보이는 표현을 `확인 필요`로 표시하고, 담당자 미정 항목에 별도 주석을 단 점이 좋았다.

Action Items는 실무적으로 보기 좋게 정리되었고, 리스크와 후속 일정도 과제 요구 형식에 맞았다. 단, `완성하기 버튼 고정 표시`나 `사진 장수 제한 15장 방향`처럼 논의 중인 내용을 다소 결정된 것처럼 표현한 부분이 있어 정확성에서 약간 감점했다.

### Gemini 결과 요약

Gemini는 가장 간결하게 핵심을 정리했고, 한줄 요약과 주요 Action Items의 가독성이 좋았다. 출력 형식도 큰 틀에서는 요구사항을 따랐다.

하지만 긴 회의의 세부 논의를 많이 생략했고, `영상 생성 에러 처리 로직 추가`의 마감일을 `내일까지`로 단정하는 등 원문 근거가 불명확한 정보를 확정적으로 표현한 부분이 있었다. 모호한 내용에 대한 `확인 필요` 표시는 있었지만 Claude나 ChatGPT보다 제한적이었다.

## 7. 최종 선정 결론

최종 선정 모델은 **Claude**로 한다.

Claude는 스타트업 회의록 요약 과업에서 가장 중요한 `불명확한 정보 처리`와 `실행 항목 정리`를 안정적으로 수행했다. 특히 원문에 담당자나 마감일이 명확하지 않은 경우 미정 또는 확인 필요로 표시해 환각 가능성을 줄였다.

ChatGPT도 포괄성과 문서 완성도는 높았지만, 논의 중인 내용을 결정사항으로 넓게 분류하는 경향이 있었다. Gemini는 간결성은 좋았으나 긴 회의의 맥락을 충분히 반영하지 못하고 일부 정보를 단정적으로 표현했다.

따라서 실제 스타트업 회의록 자동화처럼 긴 녹취록에서 결정사항, 실행 항목, 리스크, 확인 필요 사항을 분리해야 하는 업무에는 Claude가 가장 적합하다고 판단한다.
